# Guía de Configuración y Personalización de Tablas de Surf

Este documento detalla las opciones de personalización disponibles para cada tipo de tabla de surf. Al seleccionar un modelo de tabla específico, se habilitan componentes exclusivos (tipo de cola, configuración de quillas y sistema de anclaje) para la fabricación del producto final.
